# 🌍 Earth 3D Open World Game

A cartoon-style third-person 3D open world game made with Babylon.js.  
Walk around as a human character, explore a natural terrain, and enjoy Earth-style vibes.

![Earth 3D Game Screenshot](preview.jpg)

### 🎮 Controls
- `W`, `A`, `S`, `D` or Arrow keys — Move
- `Space` — Jump
- `F` — Fullscreen toggle
- Mouse — Rotates camera around the character

### 💻 How It Works
- Fully browser-based using [Babylon.js](https://www.babylonjs.com/)
- Loads instantly (no install needed)
- Works on MacBook, Windows, and mobile browsers

👉 [Click to play the game](https://ryanplayzz.github.io/earth-3d-game)
